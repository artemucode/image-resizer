# Image Resizer

Простая программа для изменения размера изображений, написанная на Python и Tkinter.

## Возможности

- Выбор изображения
- Просмотр исходного размера
- Указание ширины и высоты
- Выбор папки для сохранения
- Сохранение изменённого изображения
- Обработка ошибок
- Поддержка популярных форматов изображений
- Простой и минималистичный интерфейс

## Поддерживаемые форматы

- JPG
- JPEG
- PNG
- BMP
- GIF
- TIFF
- WEBP

## Готовая версия
