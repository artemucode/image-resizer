**Image Resizer** — это настольное приложение на Python для удобной пакетной обработки изображений. Программа позволяет быстро изменять размеры файлов, конвертировать форматы и настраивать степень сжатия через интуитивный графический интерфейс.

---

## 📋 Основные возможности

* **Пакетная обработка**: Загружайте и обрабатывайте десятки изображений за один клик.
* **Предпросмотр**: Просматривайте миниатюру и исходное разрешение выбранного файла из списка.
* **Сохранение пропорций**: Автоматический пересчет высоты при изменении ширины (и наоборот).
* **Конвертация форматов**: Поддержка экспортных форматов `JPEG`, `PNG`, `WEBP`, `BMP`, `GIF` и `TIFF`.
* **Управление качеством**:
  * Ползунок сжатия (1–100%) для форматов `JPEG` и `WEBP`.
  * Интеллектуальная блокировка ползунка качества при выборе форматов без потерь (PNG, BMP и др.).
* **Корректная работа с альфа-каналом**: Автоматическая конвертация изображений с прозрачностью (RGBA) в RGB при экспорте в JPG.
* **Безопасность**: Защита от ввода слишком больших значений (ограничение до 10 000 px) и валидация битых файлов.

## 🛠️ Требования

Для запуска из исходного кода требуется **Python 3.8+**.

Используемые библиотеки:
* `tkinter` (входит в стандартный комплект поставки Python)
* `Pillow` (PIL) — для обработки графики
* `pathlib`, `webbrowser`, `os` — системные модули
